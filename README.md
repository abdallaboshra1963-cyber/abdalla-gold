# عبدالله بشرى — V15 Commercial Core / NEBU Integration Ready

هذه النسخة مبنية على V14.1 كنقطة أساس، وتركز على تثبيت النواة التجارية قبل التكامل الفعلي مع NEBU.

## أهم الإصلاحات
- الصفحة الرئيسية أصبحت أخف: الأقسام الثقيلة تفتح عند الطلب بدل عرض كل النماذج في شاشة واحدة.
- كتالوج الشراء لا يعرض المنتجات قبل اختيار فلتر.
- النتائج محدودة إلى 12 منتجًا في الصفحة مع تنقل بين الصفحات وتحميل صور lazy.
- فلتر الشركات يحتوي على الشركات المعروفة ويُحدّث حسب النوع والعيار.
- إزالة المنتجات الافتراضية الاصطناعية من كتالوج الشراء؛ السبائك والجنيهات لها ركن مستقل.
- صور المنتجات التجريبية تستخدم placeholder بدل صورة المحل نفسها لكل المنتجات.
- شريط الأسعار يعرض بيع وشراء 24/21/18 بشكل منفصل.
- محرك أسعار إداري: مصدر المعادلة أو سوق مصري يدوي + تعديل بيع/شراء المحل.
- نقطة API خاصة بحفظ إعدادات الأسعار في قاعدة البيانات عند تهيئة Supabase.
- موصل NEBU جاهز لبيانات الشركة الرسمية دون اختراع API غير موثق.
- قسم إدارة خاص لا يظهر للعامة.

## قبل الإنتاج
تحتاج النسخة إلى:
- Supabase Auth وقاعدة البيانات والتخزين الخاص.
- SMTP/Resend حقيقي للرسائل.
- إعدادات Vercel Environment Variables.
- بيانات التكامل الرسمية من NEBU.
- نطاق Domain نهائي.
- اختبار Sandbox كامل قبل أي كتابة Production في NEBU.

لا تعتبر أي قيمة محلية في LocalStorage مصدر مخزون أو ملكية في التشغيل التجاري.
